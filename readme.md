# Dashboard de Análise de Vendas

## Sobre o projeto

Este projeto consiste em um dashboard interativo desenvolvido para simular o acompanhamento de indicadores comerciais de uma empresa.

A aplicação permite visualizar informações de faturamento, quantidade de vendas, ticket médio, desempenho mensal e produtos mais vendidos.

## Objetivo

Desenvolver uma ferramenta simples de análise de dados comerciais, facilitando a visualização de resultados e o acompanhamento do desempenho das vendas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Visualização do faturamento total.
- Contagem da quantidade de vendas.
- Cálculo automático do ticket médio.
- Gráfico de faturamento por mês.
- Lista de produtos mais vendidos.
- Filtro de vendas por período.
- Layout adaptável para celulares e computadores.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html no navegador.
4. Utilize o filtro de período para visualizar os indicadores.

## Dados utilizados

O projeto utiliza dados fictícios de vendas, criados para demonstrar o funcionamento do dashboard.
